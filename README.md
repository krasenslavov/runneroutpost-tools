# RunnerOutpost tools

Free, open-source tools for running groups, by [RunnerOutpost](https://runneroutpost.com). MIT licence.

| Folder | What it is |
| --- | --- |
| `packages/runner-tools` | `runneroutpost-tools` on npm: schedule text to a calendar file, a GPX privacy trimmer and a meeting-time planner. |
| `extension` | RunnerOutpost Group Run Tools, a browser extension (Chrome, Edge, Firefox, Opera) with the three tools. Asks for no permissions and collects nothing. |

The same tools run in the browser at https://blog.runneroutpost.com/tools/.

This repository is exported from the RunnerOutpost source; the tools share a few files with the app. See each folder for details.
